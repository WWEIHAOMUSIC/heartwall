# 演示素材来源说明（CREDITS）

本目录用于开源版的「开箱即看」演示。仓库里有两套演示素材，用途不同。

## photos/（12 张演示图）—— clone 后直接跑用

- **生成方式**：由 ffmpeg 的 `testsrc2` 测试图 + hue 色相旋转生成（1200×800）
- **授权**：程序生成的合成图像，**不涉及任何真实人物、场景与版权**，可自由分发
- **用途**：clone 后放进 `photos/` 即可完整体验三幕动效

## gif-source/（4 张动物图）—— README 首屏 GIF 的素材

- **内容**：橘猫 / 蓝金刚鹦鹉 / 赤狐 / 金毛犬
- **生成方式**：AI 文生图（ImageGen，1536×1024 high 质量），
  已用 ffmpeg `crop` 裁掉右下角的「AI生成」水印（裁掉右 15%、下 8%，
  四张的主体都不在右下角，构图未受损）
- **授权**：AI 生成的合成图像，无真实人物、无第三方版权；
  作为仓库内演示集可自由分发，**不可单独作为商品售卖**
- **用途**：README 首屏 `docs/demo.gif` 就是把这 4 张随机铺成 43 张后实跑录制的
- **复现命令**见 [README](../README.md) 首屏 GIF 下方的注释

## music/（待补）

## 替换为自己的照片

把 `demo/photos/` 里的文件复制到项目根目录的 `photos/` 即可完整体验；
或直接把自己的照片放进 `photos/`（支持 jpg / jpeg / png / gif / webp）。

```bash
cp demo/photos/*.jpg photos/
```

## 贡献素材须知

如需补充演示素材，请确保满足以下任一条件，并在本文件登记来源：

1. 自拍 / 自制，且画面中人物已签署肖像授权
2. 商用图库素材，且授权条款允许「作为软件演示集再分发」
3. 程序或 AI 生成的合成图像（无真实人物、无第三方版权）

> ⚠️ Pexels / Unsplash 等图库虽允许免费商用，但多数**禁止把含人物的照片做成可再分发的产品**。
> 作为仓库内演示集（不单独售卖）可以使用；商品模板中的含人物照片必须替换为已签授权的自拍。
